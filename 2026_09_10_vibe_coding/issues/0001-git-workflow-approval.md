## מה הבעיה

הסוכן הניח, בלי לשאול, כלל Git מחמיר לפרויקט: ענף לכל משימה
(`feat/<שם>-<slug>`), קומיט רק לבקשת אדם, ו-`main` מתעדכן ב-merge בלבד
אחרי שאדם קרא את השינוי. ה-`readme.md` בשורש ה-repo מלמד זרימה ישירה
ל-`main`, שמתאימה לעובד יחיד. שני הכללים סותרים, וסוכן אינו מכריע בסתירה.

## איך משחזרים

השוואה בין סעיף "Git" ב-`README.md` של הפרויקט וסעיף 6 ב-
`docs/conventions/collaboration-rules.md`, לבין `readme.md` בשורש ה-repo.

## מה נדרש כדי לסגור

תומר מאשר את הכלל כמו שהוא, או מרכך אותו. ההכרעה נרשמת ב-`docs/decisions/`
והמסמכים מעודכנים בהתאם.
