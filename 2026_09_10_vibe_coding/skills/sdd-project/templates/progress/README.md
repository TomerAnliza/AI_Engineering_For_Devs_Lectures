# progress — איפה הפרויקט עומד עכשיו

תיקיית **המצב הנוכחי**. בניגוד ליומן, שהוא היסטוריה שרק מוסיפים לה, כאן
יש קובץ חי אחד שמתאר את ההווה ומתעדכן במקום.

| קובץ | תפקיד |
|---|---|
| `status.md` | תמונת מצב: מה גמור, מה בעבודה, מה חסום, מה הבא. **מתעדכן בסוף כל סשן** |

## מי קורא את זה

אדם או סוכן שנכנסים לפרויקט ורוצים תשובה לשאלה אחת: **"איפה אנחנו?"**
בלי לקרוא עשר רשומות יומן.

## מי כותב

מי שסיים סשן. הוא מזיז שורות בין הסעיפים: מ"בעבודה" ל"גמור", מ"הבא"
ל"בעבודה". כל שורה מפנה לתוכנית או לתקלה שממנה היא באה.

## הקשר לשאר

```text
issues/  →  מה שבור או חסר          (הבעיה)
specs/   →  מה בדיוק נדרש           (הדרישות)
plans/   →  איך נפתור                (הדרך)
docs/journal/ → מה נעשה בפועל        (ההיסטוריה)
progress/ → איפה זה עומד עכשיו       (ההווה)
```
